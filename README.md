# Ecommerce Project

A full-stack ecommerce web application built with React and a separate backend API.

The project demonstrates frontend development, REST API integration, product management, shopping cart functionality, checkout flow, and automated testing.

## 🚀 Features

* Product listing
* Product search and filtering
* Shopping cart
* Checkout flow
* Order summary
* Responsive user interface
* REST API integration
* Backend API
* Automated frontend testing

## 🛠️ Technologies Used

### Frontend

* React
* JavaScript
* React Router
* Axios
* Vite
* CSS
* Vitest
* React Testing Library

### Backend

* Node.js
* Express.js
* REST APIs
* CORS

```text
React Frontend
      ↓

      ↓
Express Backend
      ↓
Data / API Response
      ↓
React UI
```
